# Haven Sitters website

A one-page site for Haven Sitters: plain HTML, CSS and a little JavaScript, with no build step. It's hosted free on GitHub Pages.

## Files
- `index.html` has all the page content
- `styles.css` has the brand colors, fonts and layout (colors are at the top)
- `sitters.js` holds the sitter showcase; add new sitters here
- `logo.png`, `nahli.jpg` and `bianca.jpg` are the images

Only add sitters who have agreed to be on the site.
